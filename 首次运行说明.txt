视频下载工具 · 朋友安装版

1. 解压整个 ZIP。
2. 双击 ZIP 解压后根目录的“安装并启动.cmd”。安装过程会把 Python 安装在当前 Windows 用户目录，并自动装好 yt-dlp、FFmpeg 和 FFprobe。
3. 首次安装需要联网：Python 安装文件已随包提供；FFmpeg/FFprobe 会从发布站点下载约 109 MB，并先核对 SHA-256，再复制到工具目录。
4. 安装完成后，可从开始菜单打开“B 站视频下载工具”。默认视频保存到当前用户的 Videos\BiliDownload，也可在主界面更改。

不需要单独安装 Python 或手动配置 FFmpeg。安装器不请求管理员权限，不会读取原电脑的设置、Cookie、任务历史或下载视频。

需要登录画质时，可以使用随包提供的 Chrome Cookie 导出扩展（无需再下载插件）：先按“浏览器Cookie插件\安装说明.txt”安装一次，然后运行安装目录“浏览器Cookie插件\打开扩展管理.cmd”，在 Chrome 中按说明加载随包扩展；在已登录 B 站的 Chrome 中导出自己账号的 Cookie 文件，并在工具里选择。Cookie 等同于登录凭据，只保存在自己的电脑上，不要发送给别人，也不要放进安装包。

此包针对 64 位 Windows 10/11；需要联网完成首次安装。若网络中断，重新运行安装程序即可继续。

FFmpeg 的构建和许可信息见“安装程序\FFmpeg 来源与许可.txt”。Python 版本和发布信息见“安装程序\Python 来源与许可.txt”。
