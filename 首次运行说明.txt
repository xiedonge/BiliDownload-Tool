视频下载工具 1.1.0 · 朋友安装版

1. 解压整个 ZIP，双击根目录“安装并启动.cmd”。
2. Python 安装程序和 Python 依赖已随包提供；缺少 FFmpeg/FFprobe 时仍需联网下载约 109 MB，安装器会核对校验值。
3. 安装完成后从开始菜单打开“B 站视频下载工具”。
4. 进入“账号”页，生成二维码，用手机 B 站 App 扫码并确认。不需要安装 Chrome 插件。
5. 回到“下载”页，粘贴链接，识别并检查画质，再点击“预览并下载”确认范围、画质和保存位置。

“记住登录”默认勾选，扫码成功后只在当前 Windows 用户下加密保存；扫码前取消勾选则仅用于本次运行。不要把会话文件或导出的 Cookie 发给别人。
默认视频保存到当前用户的 Videos\BiliDownload，可在设置页更改。已有的 Cookie 文件导入和附带的导出插件仅作为兼容方式。

适用于 Windows 10/11 x64。下载与登录需要网络。运行同一个安装程序可重试安装。
使用说明与本版验证边界见“新版使用说明.md”。
